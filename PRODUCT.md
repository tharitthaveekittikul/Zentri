# Product

## Register

product

## Users

DIY investors managing a mixed portfolio (US stocks, Thai stocks, Thai mutual funds, crypto, gold). Currently built for a single user but designed to be shareable — should feel polished enough that showing it to others doesn't require an apology. The user is technically capable (runs their own Docker stack) but uses the app in a personal, private context, not in a trading pit. They come to the dashboard to make decisions, not to watch numbers move.

## Product Purpose

Privacy-first personal financial OS. Zentri aggregates holdings across asset classes into one view, auto-fetches prices, and uses an LLM to read the documents the user doesn't have time for — fund prospectuses, filings, reports — then delivers reasoned BUY / SELL / HOLD recommendations in plain language. Everything runs locally. Financial data never leaves the machine. Success looks like: a user opens Zentri, understands their financial position in under a minute, and knows what action (if any) to take today.

## Brand Personality

Calm, composed, trustworthy. A private advisor who has already read everything — not a trading platform trying to manufacture urgency. Three words: **measured, lucid, considered**.

## Anti-references

- **Robinhood / crypto-native apps** — gamified green/red, confetti on trades, designed to maximize engagement and trades. Zentri is the opposite of addictive.
- **Generic SaaS cream** — purple gradient heroes, floating glass cards, "modern startup" templates. Interchangeable and meaningless.
- **Bloomberg Terminal** — overwhelming data density, no breathing room, treats every pixel as a cell in a spreadsheet. Zentri synthesizes; it does not merely dump.
- **Dark neon / cyberpunk** — neon glows, matrix vibes, techno-hype. Antithetical to calm and trust.

## Design Principles

1. **Counsel over data.** Zentri synthesizes, it doesn't just display. The interface should distinguish raw numbers from interpreted insight. A recommendation should look different from a data point.
2. **Confidence through clarity.** Never make the user hunt for what matters. Hierarchy, grouping, and emphasis should do the work — not decoration.
3. **Unhurried precision.** Spacing, rhythm, and pacing should signal thoughtfulness. Decisions about money are not made in a hurry.
4. **Privacy as a design statement.** Local-first is not a technical footnote — it is a promise. The interface should feel personal and contained, not like a dashboard phoning home to a SaaS company.
5. **Polished enough to share.** Personal tool aesthetics (hacked-together, rough edges, personal-project vibe) are not the target. The interface should hold up when someone else sits down at it.

## Accessibility & Inclusion

WCAG AA minimum: 4.5:1 contrast ratio on all text, keyboard-navigable throughout, focus indicators present and visible. Respect `prefers-reduced-motion`. No color-only encoding for financial signals (BUY/SELL/HOLD must use label + color, never color alone).
